# 独立版 Imagen 参数编辑升级

2026-10-13：本仓库的 Vue/FastAPI 独立版已实现参数编辑、草稿与预设、蒙版上传和完整设置复用。原始方案见[升级草案](parameter-editing-upgrade-draft.zh-CN.md)。

[正式站点](https://bunnykloud.site/index/workshop/imagen)运行 PersonalStation 的原生 Svelte/Rust 版本，说明见[原生参数编辑文档](https://github.com/klpzj/PersonalStation/blob/main/docs/imagen-parameters.md)。两者的参数边界各有契约：本文独立版数量为 1–2、留空超时使用 SDK 默认值；原生版数量为 1–10、超时为 1–600 秒且默认 600 秒。本文的实现和测试结果不代表旧 Vue/FastAPI 服务已部署到正式站点。

## 操作方式

所有下拉框都可以直接输入。点击箭头查看建议，输入时筛选候选；方向键选择、Enter 确认、Esc 收起，中文输入法选词不会提交表单。自定义值保留并标记，切换模式或配置加载不会替换它。

生成与编辑各自保存提示词和参数草稿。草稿、命名预设保存在当前浏览器，支持参数导入/导出 JSON、重置、一次撤销和历史完整设置复用。预设只修改参数；未知名称可用“保存预设”另存，输入名称不会改动草稿。

提交后可以继续准备下一次草稿，运行中的请求仍使用提交时的设置。生成任务持久化并可在刷新后恢复状态；失败设置可载入、修改后手动重试。请求不会自动删掉参数、替换值或重试。

## 可编辑参数

| 参数 | 支持与约束 |
| --- | --- |
| 模型、质量 | 建议值和自定义文本；自定义值交给已配置的图像服务校验 |
| 尺寸 | `auto` 或正整数 `宽x高`；宽高输入、方向交换、快捷尺寸和比例显示 |
| 格式 | 可输入 `png` / `jpeg` / `webp`；本地只保存这些实际图片格式 |
| 数量 | 1–2 的整数；超限显示错误并保留输入 |
| 背景 | 服务默认、`auto`、`transparent`、`opaque` 或自定义；JPEG 与透明背景冲突时提示 |
| 输出压缩 | 留空或 0–100；PNG 请求省略此项，草稿值保留 |
| 输入图保真度 | 编辑专用；`low` / `high` 或自定义 |
| 风格 | 生成专用；`natural` / `vivid` 或自定义，需服务支持 |
| 审查、响应形式 | 可选或自定义；空白表示不发送，服务仍使用自身规则 |
| 请求超时 | 可选正数秒数；留空使用 SDK 默认超时 |
| 扩展参数 | JSON 对象；保留 `0` / `false`，不能覆盖专用参数、身份或服务设置 |
| 提示词 | 两个模式均允许最多 32000 字符；服务可能有更低限制 |

“服务默认”代表省略参数；`auto` 是明确发送的值。候选列表是建议，具体服务与模型的参数范围以其实际支持为准。字段错误显示在对应控件旁，正在编辑的新草稿不会被旧请求的错误标记。

“查看本次有效参数”显示草稿将提交的参数。结果记录保存完整有效选项和实际文件格式；请求未指定模型时记录服务器最终选用的默认模型。旧历史仍能读取，复用时说明哪些参数缺失。

## 编辑素材与蒙版

上传、拖拽或在上传区粘贴图片后，图片直接加入输入列表。上传图片可保留为素材，输入列表支持上移、下移和移除，列表顺序就是请求顺序。历史图片可直接加入编辑。

可上传包含透明通道、大小小于 4 MB 的 PNG 蒙版；透明区域指定编辑范围，对应输入列表第一张图片，尺寸必须一致。后端在发送上游请求前检查真实图片格式、透明通道和尺寸。

浏览器刷新不能恢复上传文件。界面会列出需重新添加的文件，并提醒核对输入顺序；历史素材按 ID 恢复，已删除的素材会提示。结果复用可恢复历史引用和完整参数，上传图与蒙版需重新添加。

## 依赖与验证

使用 `openai>=2.0.0`、`pillow>=10`，更新已有环境：

```powershell
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
cd webui
npm run build
npm run test:ui
```

后端 13 项测试使用临时目录、合成图片与 HTTP MockTransport，覆盖真实 SDK 请求序列化、完整参数保存、JSON/multipart 校验、蒙版与输入顺序、旧数据、任务快照和失败字段。已分别通过 OpenAI SDK 2.0.0 与本机 2.44.0。

页面 37 项检查使用构建后的真实 Vue 应用、独立 mock HTTP 服务与浏览器配置目录。覆盖可输入选择框、预设、模式切换、刷新、生成 POST、编辑 multipart、任务错误和设置复用，以及桌面、390 像素手机和站点嵌入路径。Windows 默认使用 Edge；其他系统可设置 `IMAGEN_BROWSER_BINARY`。截图保存于 `.run/parameter-workspace-live-desktop.png` 和 `.run/parameter-workspace-live-mobile.png`。

本轮验证未调用实际收费图像服务。高级字段在兼容服务上的实际支持范围仍需使用该服务验证。

## 后续能力
